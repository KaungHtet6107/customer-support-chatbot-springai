Spring AI Service Layer - Customer Support Chatbot


In this project, you will build a simple customer support chatbot backend using Spring Boot and Google's Gemini AI API. 
This chatbot will take customer queries, send them to the Gemini AI model, and return helpful responses.



Objectives:


Set up a Spring Boot application


Configure the Gemini AI API


Create a REST endpoint for chatbot queries


Test the application using curl


Incorporate a challenge exercise (optional)



Prerequisites


Knowledge of Java, Spring and REST APIs


A Google account for accessing the Gemini API
